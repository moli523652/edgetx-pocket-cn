本固件基于 EdgeTX 官方 v2.11.3 源码深度改造，以下为核心
改动清单，供二次开发参考。

--------------------------------------------------------------
一、中文字库支持（外置字库方案）
--------------------------------------------------------------
1. radio/src/gui/128x64/lcd.h
   - 新增 #define FH 11（中文行高；BOOT 模式下保持 8）
   - 中文行高 11px 与 7px 英文字符混排的对齐方案

2. radio/src/gui/128x64/cnfont.h / cnfont.cpp（新增文件）
   - 外置字库加载器：从 SD 卡 RADIO/CNFONT/cnfont.bin 读取
     11x11 点阵中文字形
   - 覆盖范围：CJK 统一表意文字（U+4E00-U+9FFF）、
     全角符号（U+FF00-U+FFEF）、CJK 标点（U+3000-U+303F）

3. radio/src/gui/128x64/lcd.cpp
   - getCharPattern() 增加 CJK 分支：命中中文字符码位时
     从外置字库取字形，缺字/无字库时输出空白占位保持排版
   - lcdDrawChar() 对 11px 中文字形做垂直偏移，
     与 7px 英文光学居中对齐
   - getTextWidth() 同步支持中文宽度计算

4. 字库文件
   - cnfont.bin（16,418 字节，11x11 点阵）
   - 放置位置：SD 卡 RADIO/CNFONT/cnfont.bin
   - 缺失时固件正常启动，中文位置显示为空白（不崩溃）

--------------------------------------------------------------
五、构建方法（如需自行编译）
--------------------------------------------------------------
构建环境：
  - Windows + ARM GCC 14.2.1
  - Ninja 构建系统
  - EdgeTX 2.11.3 源码树

cmake 配置（Pocket）：
  -DPCB=X7 -DPCBREV=POCKET -DTRANSLATIONS=CN
  -DCMAKE_BUILD_TYPE=Release -DUSE_UNSUPPORTED_TOOLCHAIN=ON

构建命令：
  ninja -C build firmware
  产物：build/arm-none-eabi/firmware.bin

注意：superbuild 顶层 build.ninja 需把 $(MAKE) 替换为 ninja；
      cmake 重新配置后需重新打补丁。

--------------------------------------------------------------
六、Flash 布局（Pocket）
--------------------------------------------------------------
  - 0x08000000 起：bootloader（32KB，0x8000）
  - 0x08008000 起：application（APP 向量在固件偏移 0x8000）
  - 芯片：STM32F407（X7 平台），Flash 1MB
  - 固件 515,764 字节，未超 Flash 容量

--------------------------------------------------------------
七、重要提示
--------------------------------------------------------------
  - 本固件只适用于 RadioMaster Pocket（128x64 黑白屏）
  - Pocket 与 Zorro 同为 X7 平台、128x64 屏，但 PCBREV 不同，
    固件不能互相刷写（Pocket=PCBREV POCKET，Zorro=PCBREV ZORRO）
  - Pocket 支持 SD 卡 Write Firmware 刷写；如个别设备 SD 刷
    失败，可改用 USB DFU（见 README）
  - 固件发布遵循作者意愿，保留「莫漓 moli」署名
