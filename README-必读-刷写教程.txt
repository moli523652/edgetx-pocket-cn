【这是什么】
  - 基于 EdgeTX v2.11.3 深度中文化的自研固件（非官方、非他人成品）
  - 全界面中文汉化：系统设置、模型设置、混控、遥测、工具等
  - 外置 11x11 点阵中文字库，笔画清晰、显示稳定
  - 开机画面带「莫漓」中文防伪水印

--------------------------------------------------------------
【适用机型与版本 - 刷前必看】
--------------------------------------------------------------
  适用：
  - RadioMaster Pocket（128x64 黑白屏）
  - 内部模块 ELRS 版、4in1 版、CC2500 版均支持
    （固件已内置 ELRS / Multi多协议 / CRSF / GHOST /
      DSM / SBUS / CC2500 等全部协议，自动识别硬件）

  不适用（刷错会黑屏/变砖）：
  - 其他机型：Zorro、Boxer、T-Lite、T-Pro 等
    即使同样是 128x64 屏幕，PCB 配置不同，也不能刷本固件
  - 若不确定机型，在【系统设置 -> 版本】页查看，机型应显示 Pocket

  刷前确认当前固件版本：
  - 【系统设置 -> 版本】页可看到当前 EdgeTX 版本号
    （可能是 2.8 / 2.9 / 2.10 等，都可以刷本固件）

【重要警告 - 必读】
  1. 刷写前请先【完整备份 SD 卡】（整卡复制到电脑），
     尤其是 RADIO/radio.bin 和 MODELS/ 文件夹。
     这是你能安全回退的前提。

--------------------------------------------------------------
【从不同版本升级（重要）】
--------------------------------------------------------------
  无论你当前是 2.8 / 2.9 / 2.10 还是其他版本：
  - 刷到 2.11.3 后，第一次开机会【自动迁移】现有的
    设置和模型（radio.bin / models.bin 会自动转换）
  - 一般情况下模型和设置会原样保留，无需手动操作
  - 模型里若引用了图片/声音，它们是按路径引用的，
    请确保 SD 卡内容完整（不要只备份部分文件）

  升级后万一模型显示异常：
  - 可用电脑端 EdgeTX Companion 软件读取/转换
  - 或直接恢复刷前备份的 SD 卡内容

  关于回退（刷回旧版）：
  - 旧版固件【读不了】新版固件转换过的数据格式
  - 所以回退旧版时，必须同时恢复旧版备份的 SD 卡数据
  - 没有备份就不要回退，否则模型可能丢失

  SD 卡内容说明：
  - 本固件运行中文只依赖 cnfont.bin，不依赖其他 SD 内容
  - 老版本 SD 卡可以继续使用，无需强制更新

--------------------------------------------------------------
【刷写步骤 - 方式一：SD 卡刷写（推荐，免工具免驱动）】
--------------------------------------------------------------
第 1 步：放固件
  1. 遥控关机，USB-C 连电脑，遥控上选择 USB Storage（U 盘模式）
  2. 把 01-Firmware固件/pocket-cn-moli.bin 复制到 SD 卡
     【FIRMWARE】文件夹
  3. 安全弹出，拔线

第 2 步：刷固件
  4. 关机状态下，【按住左右两个水平微调键（trim）不放，
     再按电源键开机】，进入 Bootloader 模式
  5. 用滚轮选择【Write Firmware】-> 选中 pocket-cn-moli.bin
     -> 确认刷写
  6. 刷完自动重启

第 3 步：放字库（重要！不放字库中文会显示为空白）
  7. 再次进 U 盘模式
  8. 在 SD 卡【RADIO】文件夹里新建【CNFONT】文件夹
  9. 把 02-CNFONT字库/cnfont.bin 放进去，最终路径是：
     SD卡:\RADIO\CNFONT\cnfont.bin
  10. 安全弹出

第 4 步：设置语言并验收
  11. 开机 -> 系统设置 -> 语言 -> 选简体中文
  12. 开机画面应有「莫漓」水印；第一次开机若有"正在转换
      模型/设置"提示，属正常现象

--------------------------------------------------------------
【刷写步骤 - 方式二：USB DFU（备选，仅当 SD 卡刷失败）】
--------------------------------------------------------------
  适用：个别设备 SD 卡刷写报错时使用。

  1. 进入 bootloader（双水平微调+开机），选择 USB DFU
  2. 安装驱动（仅第一次）：
     - 打开设备管理器，找到带黄叹号的 STM32 / DFU 设备
     - 右键 -> 更新驱动 -> 浏览 -> 从可用列表选取
     - 选择 WinUSB 设备，完成安装
  3. 打开命令提示符，进入
     03-刷写工具/dfu-util-0.9-win64 目录
  4. 把 pocket-cn-moli.bin 放到该目录，执行：
     dfu-util -a 0 -s 0x08000000:leave -D pocket-cn-moli.bin
  5. 看到 "File downloaded successfully" 即成功
     （"Invalid DFU suffix signature" 是正常提示，不用管）
  6. 之后仍需按方式一第 3 步放字库

【常见问题排查】
--------------------------------------------------------------
Q1: 进 U 盘模式后电脑看不到 SD 卡？
  - 确认用的是【数据线】不是充电线
  - 遥控开机后要在菜单里选 USB Storage（U 盘模式）
  - 换一个 USB 口/换线再试

Q2: SD 卡刷写时提示固件错误 / 刷不进去？
  - 确认固件放在 SD 卡【FIRMWARE】文件夹
  - 确认刷的是 Pocket 固件（不是 Zorro 等其他机型）
  - 仍失败就改用方式二 USB DFU

Q3: 刷完开机，中文位置是空白/方块？
  - 字库没放对。确认 SD 卡里有 RADIO/CNFONT/cnfont.bin
  - 确认文件名完全一致（cnfont.bin，小写）

Q4: 刷完开机模型/设置不见了或异常？
  - 第一次开机自动迁移需要一点时间，先正常关机再开机看
  - 仍异常就用 EdgeTX Companion 或恢复备份的 SD 卡

Q5: 怎么验证固件是正版？
  - 运行 04-固件校验/verify_new_fw.py（需电脑装了 Python）
  - 输出 "anti-tamper check: PASS" 即正版
  - 固件内嵌 "Custom by moli" 签名，可被溯源

Q6: 想刷回官方/旧版固件？
  - 官网下载对应固件，同样用 SD 卡或 DFU 刷回
  - 回退后务必恢复旧版备份的 SD 卡数据（旧版读不了新数据）
